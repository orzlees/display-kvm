# displayKvm 文档

项目已包含后台、命令行、桌面界面和候选构建流程。开发与验收状态以[总任务计划](任务计划/【20261105-显示器切换工具开发】.md)为准；当前系列包含 30 项任务，任务 24 继续承担唯一末尾全量软件验证及多环境实机验收。

| 入口 | 用途 | 当前状态 |
| --- | --- | --- |
| [产品与架构](design.md) | 需求、候选架构、平台限制与来源 | 草案待评审 |
| [交互与视觉](ui-design.md) | 非 Web 桌面的操作流程与视觉建议 | 历史设计草案；实现与验收状态见总任务计划 |
| [文档公开边界](documentation.md) | 哪些内容适合开源，哪些适合留在本地 | 建议待评审 |
| [开发总计划](任务计划/【20261105-显示器切换工具开发】.md) | 30 项独立任务、依赖、验收与授权边界 | 以总计划中的实施、独立验证与工件证据为准 |

面向用户和贡献者的稳定公共文档用于解释产品、使用方式与关键设计；总计划和独立待办用于内部调度、实施范围和证据追踪，是否公开可另行选择。

01–23 为既有归档；25–30 为已批准的功能、包装和文档补全范围。任务中的实施记录、独立验证结果和实际工件证据分别保留，不能把“已实现”或“交叉编译成功”视为真实设备验收完成。

Windows/Mac 的真实切屏、USB、登录、睡眠唤醒、权限会话和多屏部分失败仍须按任务 24 逐项实测，未完成前不归档任务 24。
